# 🛒 Shopping List — Android-приложение «Список покупок»

Нативное Android-приложение для ведения списка покупок с локальным хранением данных. Построено на современном стеке Kotlin + Jetpack Compose.

## Возможности

- Добавление товаров вручную
- Отметка купленных товаров (чекбокс с зачёркиванием)
- Удаление отдельных товаров
- Автосохранение в локальную базу данных
- Счётчик товаров
- Очистка всего списка
- Сортировка некупленных товаров наверх

## Технологии

- **Kotlin** — язык разработки
- **Jetpack Compose** — декларативный UI
- **Room Database** — локальное хранилище
- **Material3** — дизайн-система
- **MVVM** — архитектурный паттерн
- **Android Studio** — IDE

## Требования

- Минимальная версия: **API 24 (Android 7.0)**
- Android Studio (актуальная версия)

## Структура

```
shopping_list/
├── app/            # Код приложения
├── data/           # Room: entity, DAO, database
├── ui/             # Compose-экраны и компоненты
├── res/            # Ресурсы
├── build.gradle.kts
└── settings.gradle.kts
```

### Модель данных

Entity `ShoppingItem`:
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Int | Идентификатор (PK) |
| `name` | String | Название товара |
| `isBought` | Boolean | Куплен ли товар |

## Сборка и запуск

```bash
# Открыть проект в Android Studio
# Или собрать из командной строки:
./gradlew assembleDebug

# Установить на подключённое устройство
./gradlew installDebug
```

## Архитектура

- **MVVM:** разделение UI (Compose) и бизнес-логики (ViewModel)
- **Room:** реактивное хранилище с автосохранением
- **Compose:** декларативный UI с Material3-компонентами
